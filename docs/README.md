# docs/

Project state ledgers. Every file here is authored by this project — status, scoring, deviation, additions, session narratives, boundary acceptance. Nothing here is code or governing input; the governing inputs live under [`../specs/`](../specs/).

Start with `STATE.md`. `DOCS.md` catalogs every document (in this folder and elsewhere) with a one-line hook.

| File | Hook |
|---|---|
| [STATE.md](STATE.md) | Where the product stands against every governing document. File-and-line detail. Read first. |
| [ROADMAP.md](ROADMAP.md) | Measured gate status, everything shipped, deferred items, deliberate non-goals. |
| [HANDOFF.md](HANDOFF.md) | Ten-section project overview: what this is, where it stands, how to run it, where code and docs live, standing rules, deferred items, runbook. |
| [DOCS.md](DOCS.md) | Full catalog of every document in the repo, grouped by purpose. |
| [DEVIATION_SUMMARY.md](DEVIATION_SUMMARY.md) | Quantified delta from the initial design, how, and where the build stands. |
| [ADDITIONS.md](ADDITIONS.md) | Every capability built on top of the original doc stack. 30 rows, each with its new vocabulary and its test. |
| [RECEIVING_ACCEPTANCE.md](RECEIVING_ACCEPTANCE.md) | The receiving evidence boundary scored against its own §27 criteria. 15 of 15 pass. |
| [ACCESS_AND_VISIBILITY_ACCEPTANCE.md](ACCESS_AND_VISIBILITY_ACCEPTANCE.md) | The access and visibility boundary scored against its own §16 criteria. 18 of 18 pass or pass-in-part. |
| [PHASE_C_READOUT.md](PHASE_C_READOUT.md) | Phase C summary — 24-sprint arc, what got mapped where, what was deferred, red-team findings. |
| [SESSION_2026-08-25.md](SESSION_2026-08-25.md) | Full-day narrative of the Phase C session. Commit ledger at the bottom. |
| [SDD_GENERAL_PROCESS.md](SDD_GENERAL_PROCESS.md) | Theory note: SDD set against the settled fields that already do what it does. Not project state; the doctrine behind it. |

SDD process state (BLACKBOARD, KIT_DIARY, WORKING_AGREEMENT, ADDENDUMS) lives at project root by SDD-kit convention, not here.
