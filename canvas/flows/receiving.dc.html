  1. ReceivingQueue shows one line in the "Received · no check yet" section. Inspector opens the supplier evidence checklist for it.
  2. SupplierEvidenceChecklist shows the certificate_of_conformance requirement with no satisfying document.
  3. Inspector clicks Run receiving check on ReceivingCheckView. RunReceivingCheck returns state blocked with blockers[] containing certificate_of_conformance_present. Event RECEIVING_CHECK_BLOCKED.
  4. The system worker fires ApplyReceivingCheckResultToInventory and walks the InventoryItem to quarantined via the registered state-machine transition. Event INVENTORY_QUARANTINED.
  5. InventoryQuarantineView shows the item held. Release is disabled with the disabled-strip citing "no fresh ReceivingCheck reads passed".
