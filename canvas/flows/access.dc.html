VF-012 · Phase C access · steps walked
  1. Customer opens RunCloseReportView. GetReport under customer_summary_access returns the report at visibility level summary per the sections table.
  2. Customer drills down into receiving_evidence_summary → verified_by. BoundedDrillDown returns summary — fact of verification, no signer identity.
  3. Customer attempts receiving_evidence_summary → CAGE code. BoundedDrillDown refuses with bounded_drilldown_denied. CAGE is a hidden field on supplier_document_summary.
  4. Every hop writes an ACCESS_DECISION_AUDITED event carrying the target alias and the reason; no field from the target's data.

Phase C access flow · steps walked
  1. Support user opens a SupportSession. OpenSupportSession · rule support_session_management · scope names the report alias, expires_at is set to +1h.
  2. Under the session, support user drills down through BoundedDrillDown. Every read tags support_admin_context. Reads outside the scoped aliases refuse with support_context_missing.
  3. Support user reads the audit log on AccessDecisionAuditView. The prior customer refusal shows reason code report_audience_mismatch.
  4. Support user closes the session. CloseSupportSession · emits SUPPORT_SESSION_CLOSED. Any subsequent read refuses with support_context_missing.
