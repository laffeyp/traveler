Presentation expiry strip

sprint 134 · shared component · Phase G · time-remaining against Presentation.expires_at

Time-remaining strip for a bound Presentation. Reads Presentation.expires_at and computes remaining against world.clock. Distinct from state-badge because the badge renders a stored state (bound) and this strip renders time-relative content that state alone cannot carry. expired is a read-time predicate, not a stored state — the strip is the surface where the predicate becomes visible to the operator.

Calm · plenty of time

presentation_gasket_003 · bound at station-B4 6:43 left

Warn · under 90 seconds remaining

presentation_gasket_003 · bound at station-B4 0:47 left

Expired · handler will refuse presentation_expired

presentation_gasket_003 · bound at station-B4 expired 0:12 ago

On expired, the next handler call (Install / Bind / Consume) throws presentation_expired via the presentationExpired helper (Date.parse-based, fail-closed on unparseable input). The strip is a UI-side warning; the runtime refuses independently.

Grading

Colour uses: calm is the grey ground (no exception); warn earns amber under 90s; expired earns red once the predicate flips. The threshold (90s) is not a runtime constant — it's a UI cue only, tunable per surface. The runtime cares about the crossing at zero, not before it.
