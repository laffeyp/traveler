## What this table is for

An implementer reads one row, opens the artboard, and knows exactly
which registered names appear on the screen. Every operation, event,
state, rule id, and reason code named in this table resolves in
`contracts/*.yaml` today (measured 2026-08-26). No name here needs to
be invented, translated, or paraphrased.

## Phase G — Physical Presence UI Overlay overlay (sprints 126–138, closed 2026-08-29)

Phase G patched fifteen screens against the runtime and bench Phase E and Phase F already proved. Two replaced (ScanInventoryView, InstallInventoryView), five amended (OperatorHome, RunStepView, BlockerView, SerialHistoryView, SupportDiagnosticsView), six inspected-only with no-change decisions (MeasurementCaptureView, RunCloseReadinessView, SupplierEvidenceChecklist, ReportsHome, RunCloseReportView, RunCloseReportGenerationView). Six shared components extended (state-badge lede corrected to seventeen state-machined records); three new components added (station-chip, presentation-expiry-strip, handoff-gap-card). Four flow maps updated citing Phase F/E scenarios VF-045, VF-048, VF-052, VF-053. Two remaining markers: **handoff-F** on RunStepView and SerialHistoryView (Part-master vocabulary gap; Phase M trigger NOT FIRED for overlay reasons); **handoff-A track 2** on SupportDiagnosticsView and canvas/flows/access.dc.html (F2 track 1 access_admin workaround; sharpened trigger NOT FIRED at close). Every changed row in `manifest.yaml` under `phase_g_overlay:` names the specific evidence cited. `dev/phase-handoffs/PHASE_G_HANDOFF.md` returns the phase to the team that supplied the overlay spec.

The `handoff-E` marker is retired on the two source screens that carried it (ScanInventoryView, InstallInventoryView). It survives in the `handoffs:` table above as the historic record of Phase D's boundary question — Phase E and Phase F closed the runtime and bench side; Phase G closed the UI side. The whole-canvas HTML aggregate at `canvas/factory-ui-canvas.html` regenerates from source and mirrors the two source screens as a build artefact, not an unreviewed source.
