# specs/

Ingested governing input specifications. Each subdirectory groups one governing scope: the founding-stack that defined the first executable slice, then two boundary specifications that arrived later and each closed a bounded set of §-numbered acceptance criteria.

Every file here is READ-ONLY input to the build. Authored by outside sources (or in-repo per project convention for the access-and-visibility registry pack). Not edited by this project. Every path here is cited from [`../WORKING_AGREEMENT.md §Authority order`](../WORKING_AGREEMENT.md) — governing documents that cannot be followed from inside the repo are the phantom-authority failure this project's own practice #7 forbids.
